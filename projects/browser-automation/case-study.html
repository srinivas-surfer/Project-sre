Browser Automation Showcase

Exercise a fictional storefront and run visible browser smoke checks against its cart and checkout behavior.

The problem

A passing page-load check does not establish that a user can complete a journey.

The implementation choice

Test meaningful transitions: add an item, change quantity, enforce checkout prerequisites, and confirm a fictional order.

The sample storefront is static HTML and JavaScript. The bundled Python Playwright check uses the same visible controls.

What you can verify

  • Functional sample cart
  • Quantity and shipping controls
  • Checkout validation
  • Four browser smoke checks

Run the checks, then manually add products and choose shipping. Confirm that checkout requires the demo agreement.

Scope and limits

The on-page runner uses browser JavaScript and DOM assertions; it is not a hosted Playwright service. It places no orders, processes no payments, and makes no remote requests. A separate Playwright test file is included for local automation.

This public edition demonstrates engineering concepts. It makes no claim about measured client impact or production readiness.

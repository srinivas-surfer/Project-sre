1. The engineering story
Service Performance Reporting
A Flask and Python reporting workflow that queries OpenSearch through the dashboards search interface and renders a shareable HTML performance report.

2. Why I implemented it
The operational problem
Preparing a review means choosing a time range, executing several searches, comparing channels and endpoints, and assembling the result for another reader. Inconsistent filters or report windows can make comparisons difficult.

3. How it works
From input to outcome
Normalize the review window → Start the reporting job → Query through the search adapter

4. What changed
Automated report assembly
Repeatable queries and a shareable HTML artifact.

Ticket Label Manager

Review fictional tickets against a small set of conditional label rules, then repair labels individually or in bulk.

The problem

Tickets can be inconsistent when required labels depend on the type of work or its current status.

The implementation choice

Make requirements explicit and recompute validation after each edit. Bulk repair applies only to selected tickets.

A pure validation function drives the table and bulk action. Native form controls keep editing keyboard accessible.

What you can verify

  • Conditional incident and problem rules
  • Closure labels for resolved tickets
  • Editable ticket classifications
  • Selected-ticket bulk repair

Select two incomplete tickets and repair them. Change a ticket from incident to problem and inspect the new required category.

Scope and limits

This is an in-memory browser demonstration. It does not connect to Jira, identify actual reporters, modify real tickets, or persist changes after reload.

This public edition demonstrates engineering concepts. It makes no claim about measured client impact or production readiness.

Order Anomaly Detection

Explore hourly order patterns with a transparent statistical baseline and adjustable alert sensitivity.

The problem

Order counts naturally vary. A useful signal must explain why a change deserves investigation without treating every fluctuation as a failure.

The implementation choice

Expose the baseline, standard deviation, and threshold alongside the result so visitors can understand every decision.

Plain JavaScript computes scores in the browser. SVG renders the series; CSV export contains only synthetic values.

What you can verify

  • Three synthetic traffic scenarios
  • Adjustable Z-score threshold
  • Hourly chart and alert table
  • CSV export of the current analysis

Compare a normal day with a sudden drop. Raise the threshold and observe which alerts disappear.

Scope and limits

This demonstration uses a fixed, hand-authored baseline and a Z-score rule. It does not run the private project’s ML ensemble, learn a seasonal baseline, or send alerts. A flagged point is a review candidate, not proof of an incident.

This public edition demonstrates engineering concepts. It makes no claim about measured client impact or production readiness.

From input to explanation.

A local dataset contains gauge samples and per-interval request/error counts. Browser functions compute derived rates and chart values.

Public demo boundary

The browser uses deterministic synthetic interval measurements. CPU and memory are gauge samples; error rate is errors divided by requests. This is not a live collector or a capacity recommendation.

Files are served statically by GitHub Pages. The demonstration runs locally in your browser and uses no backend credentials, analytics trackers, or external data calls.
